JARVIS / LOCAL CHAT GUIDE

Chat with a model on your device.

The JARVIS website includes an experimental chat interface that connects to Ollama running on the same computer. It is a browser-based prototype, not the separate JARVIS Desktop application.

What you need

  • Ollama installed and running.
  • At least one model available in Ollama.
  • A browser permitted to connect to Ollama's local API.

JARVIS checks http://localhost:11434 by default. Use Local connection settings in chat if Ollama listens on a different loopback port.

Browser access and safety

Because a website and the local Ollama server are different browser origins, requests can be blocked unless Ollama allows the exact JARVIS website origin. Ollama's OLLAMA_ORIGINS setting can be used for trusted origins; see Ollama's official documentation for operating-system-specific setup.

Security: Allow only the exact trusted JARVIS origin. Do not use wildcard origins or expose Ollama to the public internet. A script running on an allowed origin could send prompts to your local model.

Data and limitations

Conversation history and the local endpoint are stored in this browser's local storage. Prompts go directly to the Ollama server configured in chat. Browser local storage is not encrypted, and this prototype has no secure credential store.

This prototype supports text chat through Ollama's model-list and streaming chat APIs. It does not include cloud providers, voice, file uploads, image understanding, computer control, native desktop packaging, or SQLite persistence. The app does not certify model language, context, or multimodal capabilities.

If the connection fails, confirm Ollama is running and that only the trusted JARVIS origin is allowed.
