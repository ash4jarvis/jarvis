JARVIS / LOCAL CHAT GUIDE

Chat with a model on your device.

The JARVIS website includes an experimental chat interface that connects to Ollama running on the same computer. It is a browser-based prototype. The early JARVIS Desktop preview reuses this Ollama chat inside a Tauri webview; it is not yet the full native assistant.

What you need

  • Ollama installed and running.
  • At least one model available in Ollama.
  • A browser or desktop webview permitted to connect to Ollama's local API.

JARVIS checks http://127.0.0.1:11434 by default. Use Local connection settings in chat if Ollama listens on a different loopback port.

Browser access and safety

The website or desktop webview and local Ollama server have different origins. Requests can be blocked unless Ollama allows the exact trusted origin. The Tauri webview origin is commonly http://tauri.localhost on Windows and tauri://localhost on macOS/Linux. See Ollama's official documentation for OS-specific OLLAMA_ORIGINS setup.

Security: Allow only the exact trusted JARVIS origin. Do not use wildcard origins or expose Ollama to the public internet. A script running on an allowed origin could send prompts to your local model.

Data and limitations

Conversation history and the local endpoint are stored in browser or desktop-webview local storage. Prompts go directly to the Ollama server configured in chat. Local storage is not encrypted, and this preview has no secure credential store.

The website chat and early Tauri desktop shell support text chat through Ollama's model-list and streaming chat APIs. They do not include cloud providers, voice, file uploads, image understanding, computer control, or SQLite persistence. The app does not certify model language, context, or multimodal capabilities.

If the connection fails, confirm Ollama is running and that only the trusted JARVIS origin is allowed.
